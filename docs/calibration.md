# 校准说明

## 入口

进入设置页，在“电池校准”分组里，你会看到这些选项：

- 串联双电芯
- 疑似状态异常时提示
- 放电也显示正值
- 使用 mAh 而非 Wh（仅影响放电详情）
- 电流单位校准
- 电池状态校准

## 什么时候需要校准

如果你遇到这些情况，优先考虑校准：

- **首次使用软件**
- 功率数值明显异常
- 功率数值为**0.00W**
- 当前记录状态总是显示 **未知** / **未充电**
- 总是无记录文件

## 校准会影响什么

电流校准影响的是 App 内展示的功率换算结果。  
如果显示口径不对，软件所有功能都将无法正常使用。

状态校准影响的是记录器对电池状态的判定。  
如果判定错误，可能导致总是无记录文件。

## 配置

### 串联双电芯

用于匹配双电芯设备的显示换算。  
如果你的设备不是这一类，不要随意打开。

### 放电也显示正值

这个选项只改变展示时的正负号表现，方便阅读。  
它不会改变记录本身的采样逻辑。

### 电流单位校准

打开“电流单位校准”页面。连接记录服务并拔掉电源后，点“开始校准”。页面使用 10 条新的放电样本判断电流单位和方向。测量成功后自动保存倍率，测量失败时可以按提示重试。

也可以用加减按钮手动调整倍率，或点“重置”恢复默认倍率。页面会立即保存修改并更新实时功率预览。正确校准后，预览中充电为正值，放电为负值。

### 电池状态校准

这个选项会影响记录器对电池状态的判定。  
如果你发现总是无记录文件或当前记录状态总是显示 **未知** / **未充电**，可以尝试在异常持续时通过这个选项来修正判定。
