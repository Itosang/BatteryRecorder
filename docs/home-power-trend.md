# 首页实时指标与当前记录

- 旧实时图表可在 `48952a7b` 的父版本中查看，路径为 `app-common/.../feature/home/component/CurrentRecordCard.kt`。旧实现只画最近 20 个采样，使用二次贝塞尔曲线、渐变填充和末端圆点。
- 当前记录使用 `SplicedColumnGroup`：摘要在上，功率/功耗与温度趋势在下方并排；窄屏或放大字体时三项纵向排列。摘要仅在记录就绪时打开详情，趋势区域不承担记录详情点击事件。
- 分组使用统一 `containerColor` 与 2dp 子项间距，按可见子项位置生成圆角；趋势保持 36dp 高，不固定裁剪文字。数字加粗，单位保持常规字重；温度极值使用独立箭头图标。
- 首页各卡片标题使用与容量与续航一致的 titleMedium。当前记录内的亮屏指标是次级内容，两项标签统一 bodySmall，数值统一 titleMedium；电量变化率使用 headlineSmall，保持主次层级。
- 当前记录摘要与趋势使用普通卡片底色：深色为 `surfaceContainerLow`，浅色为 `surfaceBright`。容量与续航卡仍分两段：上段深色混合 `surfaceContainerHighest` 与 6% `primary`，浅色混合 `surfaceContainerHigh` 与 25% `primaryContainer`；下段使用普通卡片底色。预测文字与进度条独立配色。
- 时间分布复用 RecordsStats.screenOnTimeMs 与 screenOffTimeMs，它们按有效相邻采样的正时间差累计；分母是二者之和，不使用电量或墙钟时长。computeHomeScreenTimeDistribution 计算一份结果，条宽使用原始时间比例；亮屏百分比四舍五入，息屏显示 100 减亮屏百分比。正常显示为两段 10dp 高圆角条，中间 2dp 间隙，条形与下方百分比标签间距 8dp；0%/100% 不绘制空段或保留间隙。RTL 同步镜像比例条和标签。
- 比例随当前记录统计的约 30 秒节流刷新更新，与亮屏时长同一快照；不将文件快照之外的未知屏幕状态区间补入分母。切换中、缺记录、零时长或负时长显示明确未就绪信息，不绘制伪造比例。下区时间沿用 FormatUtil，数字保持 titleMedium，时间单位使用更小的常规字重。
- 普通模式光效沿用旧源码：仅在曲线下方填充，从曲线最高点的 0.25 透明度渐变到绘图区底部的透明色，并裁剪填充区域。没有曲线上方的宽描边光晕。主线宽 2.4dp，两侧额外绘制 12dp，整体左移 4dp，不显示末端圆点，不恢复 HDR。颜色和圆角使用当前主题。
- `LoadHomeStatsUseCase.loadCurrentRecordProbe()` 在 IO 线程通过 `DaemonManager.openCurrentRecord()` 获取固定长度的只读快照，`RecordFileParser` 一次解析后供统计与趋势共用；不读取本地历史副本，也不为这次读取执行完整历史同步。`aggregateHomePowerTrend` 按实际时间聚合，最多保留 120 个点，并保留首尾时间；端点功率使用所在分桶的均值。
- 同一次读取携带温度采样（原值除以 10），生成真实温度趋势。最高、最低温度在完整采样聚合前计算，不取平滑曲线的极值；极值与趋势使用同一份文件快照，即时温度不补入极值。电流按双电芯和校准系数换算为 mA，电压从微伏换算为 mV。
- 首次加载、返回首页和当前记录统计刷新时更新历史趋势。实时统计沿用 30 秒节流；文件内容受写入刷新周期限制。
- 即时功率、电流、电压和温度继续来自采样回调；趋势不追加即时采样，也不以实时短窗口冒充整段记录。温度极值、趋势与累计统计共享文件快照。
- 两张图形通过五点三角加权平均与二次贝塞尔连线平滑。边缘使用完整窗口的 1:2:3:2:1 权重，而不是截短邻域；完整窗口的最末点权重为 1/9，点来自文件聚合结果。数据不足五点时按已有点构成对称三角权重。末端使用最近五点的趋势，存在约两点的平滑滞后；末端三个点共用同一窗口。即时数字及其他统计不受平滑影响。
- 图表贯穿对应趋势子项底部，不显示标题、范围、时间文字、基准线或圆点。保留错误和等待提示，以及范围和最新趋势值的无障碍说明。
- 横向位置仍按真实时间比例绘制。功率纵轴包含零值，最小跨度 1W；温度纵轴使用实际温度范围，最小跨度 1°C。没有足够采样时等待，读取失败时显示错误并通过 LoggerX 记录原因。
- 切换记录时清空趋势。异步实时加载在写回前核对活动记录，避免旧记录覆盖新记录。

验证：`python3 scripts/check_recent_power_trend.py`；`scripts/CheckHomePowerTrend.kt` 和 `scripts/CheckHomeScreenTimeDistribution.kt` 可分别与对应纯 Kotlin 算法文件一起用主机 Kotlin 编译器运行，不需要 Android 构建。静态与主机检查不等同于 Compose 实机布局验证。
